# Клієнтська частина (React) — Турагентство «Мандрівник»

Сучасний клієнтський веб-додаток на технології **React + Vite**, розроблений для системи «Турагентство» з реактивним бекендом на **Spring Boot WebFlux / R2DBC**.

## 🌟 Основний функціонал

1. **Каталог турів за категоріями:**
   - 🏖️ **Відпочинок (VACATION)**: морські курорти, all-inclusive, пляжний релакс.
   - 🏛️ **Екскурсія (EXCURSION)**: пізнавальні тури, музеї, історичні пам'ятки.
   - 🛍️ **Шопінг (SHOPPING)**: аутлети світових брендів, шопінг-вікенди.

2. **Гарячі («палаючі») тури:**
   - Спеціальний розділ та маркування «🔥 Палаючий тур».
   - Можливість фільтрації одним кліком.

3. **Бронювання та розрахунок вартості зі знижками:**
   - Вибір кількості осіб з перевіркою доступних місць у готелі/турі.
   - Автоматичний прозорий розрахунок:
     - Базова вартість: `ціна × к-ть осіб`
     - Персональна знижка постійного клієнта: `-X%`
     - Фінальна сума до сплати

4. **Оплата туру замовником:**
   - Розділ «Мої замовлення» зі статусами (`Очікує оплати`, `Оплачено`, `Підтверджено`, `Скасовано`).
   - Електронна оплата банківською карткою (`POST /payments`) з автоматичним переводом замовлення в статус `PAID`.

5. **Панель турагента (Менеджера):**
   - **Керування турами:** миттєве перемикання статусу туру на «Палаючий» (тумблер 🔥), додавання та видалення турів.
   - **Клієнти та знижки:** призначення статусу «Постійний клієнт» та налаштування індивідуального розміру знижки (швидкі пресети 5%, 10%, 15%, 20% або довільне значення).
   - **Моніторинг замовлень:** перегляд замовлень усіх клієнтів та керування статусами.

6. **Оформлення:**
   - Спокійний, стриманий та елегантний стиль (темно-синій сапфір, м'який бурштин для гарячих турів, свіжий смарагд для знижок/оплат, чітка типографіка без кричущих неонових елементів).
